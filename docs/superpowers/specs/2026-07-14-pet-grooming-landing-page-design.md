# 宠物洗护店单页设计规格

## 项目目标

制作一个可直接在浏览器中打开的中文宠物洗护店单页网站。页面以温暖治愈的品牌氛围吸引宠物主人，并通过清晰、短路径的预约流程引导用户提交洗护预约。

## 交付范围

- 交付一个 `index.html` 文件，CSS 与 JavaScript 全部内嵌。
- 不依赖构建工具、后端服务、外部字体或外部图片。
- 支持桌面端与移动端浏览。
- 预约仅作前端演示，不保存或发送真实信息。

## 信息架构

页面按以下顺序组织：

1. 顶部导航：品牌标识、内容锚点与预约按钮。
2. 首屏：核心价值文案、信任信息、主预约按钮和宠物洗护主题插画。
3. 核心优势：温和用品、专业护理、全程安心。
4. 洗护套餐：基础洗护、精致护理、焕新 SPA，并突出推荐项。
5. 洗护流程：健康观察、温柔清洁、造型护理、香香回家。
6. 顾客口碑：三条简短可信的体验反馈。
7. 预约区域：门店承诺与预约表单。
8. 页脚：地址、营业时间、联系电话及版权信息。

## 视觉设计

- 风格关键词：奶油色、手绘感、亲切、柔软、轻松。
- 主背景使用奶油白，焦糖橙作为行动色，鼠尾草绿作为辅助色。
- 组件使用大圆角、柔和阴影和细描边，避免锐利边角。
- 使用 CSS 图形、Emoji、爪印、泡泡与手绘线条营造宠物主题，不加载外部图片。
- 标题具有鲜明层级，正文保持高对比度和舒适行距。
- 动效保持克制，包括进入浮动、按钮反馈和平滑滚动；遵守系统的减少动态效果设置。

## 交互设计

- 顶部与内容区的“立即预约”按钮平滑滚动至预约表单。
- 表单字段包括主人称呼、手机号、宠物类型、服务项目和预约日期。
- 对必填项、手机号格式和不可选择的过往日期进行前端校验。
- 校验通过后不发送网络请求，清空表单并显示明确的成功提示。
- 导航锚点可跳转至服务、流程、评价和预约区域。

## 响应式行为

- 桌面端首屏和预约区采用双栏结构，套餐与评价使用多列卡片。
- 平板与手机端改为单栏或双栏，导航隐藏非必要链接，主要预约按钮保持清晰可点。
- 控件触摸区域不小于约 44 像素，避免横向溢出。

## 可访问性与语义

- 使用语义化的 `header`、`nav`、`main`、`section`、`form` 和 `footer`。
- 表单控件具有可见标签，键盘焦点状态清晰。
- 装饰图形不干扰辅助技术，关键信息不只依赖颜色表达。
- 页面语言设为简体中文，并提供准确的标题与描述。

## 验收标准

- `index.html` 可在无网络环境直接打开并完整显示。
- 所有导航和预约按钮能到达正确区域。
- 表单能拦截空值、错误手机号和过往日期，并在有效提交后显示成功状态。
- 常见桌面与手机宽度下无内容遮挡或横向滚动。
- 页面不包含外部资源请求、占位文本或未完成标记。

## 非目标

- 不接入真实短信、支付、地图或预约后台。
- 不实现用户账户、套餐购买和管理系统。
- 不采集或持久化用户数据。
