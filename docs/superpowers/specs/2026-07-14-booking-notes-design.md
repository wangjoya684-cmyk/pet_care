# 预约备注字段设计规格

## 目标

在预约表单中增加可选备注字段，让用户补充宠物情绪、健康状况、护理习惯和造型需求等信息，同时保持表单简洁易填。

## 字段设计

- 字段标签为“备注（选填）”，不参与必填校验。
- 使用全宽多行文本框，位于“期望到店日期”下方、提交按钮上方。
- 文本框初始高度约 90px，允许用户纵向调整，不允许横向拖宽导致布局溢出。
- 占位提示为“例如：怕吹风、容易紧张、皮肤敏感或有特殊造型需求”。
- 通过 `maxlength="200"` 将输入限制为最多 200 个字符。

## 字数统计

- 文本框右下方显示实时统计，初始为“0 / 200”。
- 每次输入后按 JavaScript 字符串长度更新计数，包括中文、英文、数字和空格。
- 计数元素与文本框通过 `aria-describedby` 关联，便于辅助技术理解限制。

## 提交行为

- 备注为选填，空内容不阻止预约提交。
- 当前预约表单仍为前端演示，不发送或保存备注内容。
- 有效提交后表单重置，备注内容清空，计数恢复为“0 / 200”。
- 现有必填项、手机号和日期校验保持不变。

## 视觉与响应式

- 文本框沿用现有输入控件的背景、边框、圆角和焦点样式。
- 桌面端和手机端均占据表单整行，不增加横向滚动。
- 字数统计使用次要文字颜色和较小字号，不与提交按钮争夺视觉注意力。

## 验收标准

- 备注框在日期与提交按钮之间显示，标签、占位文本和 200 字限制正确。
- 输入内容时字数统计实时更新，达到 200 字后无法继续输入。
- 空备注和非空备注均可完成有效表单提交。
- 提交成功后备注与计数均重置。
- 常见桌面和手机宽度无横向溢出，原有预约校验和成功反馈不受影响。
